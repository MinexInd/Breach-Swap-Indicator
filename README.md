# Breach Swap Indicator (Fabric)

**A clean, lightweight, and fully client-side mod that confirms successful Breach mace swaps with visual feedback.**

---

### ✨ Features
*   **100% Client-Side**: Works on any server (Vanilla, SMP, PvP) without needing the mod installed on the server!
*   **Perfect Swap Confirmation**: Clearly see when you land a "Perfect Swap" with a distinct, floating Purple text animation above your hotbar.
*   **Smart Detection Logic**: 
    *   Accurately detects standard **Hit → Swap** combos.
    *   **Instant Swap Support**: Recognizes high-skill "instant" swaps (swapping milliseconds before the hit registers) so you never miss a confirmation.
*   **Hotbar Visuals**: subtle pulse animation on the active slot to confirm timing.
*   **Zero Anti-Cheat Risk**: Uses pure client-side inventory monitoring (no packet manipulation or weird server interactions).

### 🛠️ Configuration & Usage
The mod is designed to be "Plug & Play" with sensible defaults optimized for PvP.

*   **Toggle HUD**: Type `/breachswaphud` in-game to instantly enable or disable the indicators.
*   **Visuals**: The "Perfect Swap" text appears only when you successfully hit an entity with a Breach-enchanted Mace immediately after a swap.

### 🚀 Compatibility
Tested and confirmed working on **Minecraft 1.21+**. Requires **Fabric API**.
